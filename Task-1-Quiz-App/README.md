# Interactive Quiz Application

An interactive quiz application built using HTML, CSS, and JavaScript.

## Features

- Dynamic question loading
- Instant feedback
- Score tracking
- Progress bar
- Responsive UI
- Restart functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download the project
2. Open `index.html` in browser
